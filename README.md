# 📦 Warehouse Priority OpenEnv  
**Last-Mile Delivery + Returns Processing Environment**

## 🚀 Overview

This project implements a **real-world warehouse simulation environment** using the OpenEnv specification.

The environment models **last-mile delivery warehouse operations**, including:

- Order processing
- Inventory management
- Returns handling
- Worker fatigue management
- Deadline-based priority escalation
- Restocking decisions

This environment allows AI agents to learn **decision-making under pressure**, similar to real logistics and fulfillment centers used by companies like Amazon, Flipkart, and logistics hubs.

---

# 🧠 Real-World Motivation

Modern warehouses face complex challenges:

- Hundreds of simultaneous orders
- Urgent delivery deadlines
- Customer returns disrupting workflows
- Limited workers and inventory
- Dynamic priority escalation

This environment simulates those real-world conditions so AI agents can learn:

- Scheduling decisions
- Resource optimization
- Risk management
- Deadline handling
- Inventory balancing

This makes the environment **useful for training intelligent logistics agents**, not just toy simulations.
